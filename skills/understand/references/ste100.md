# ASD-STE100, the working rules

ASD-STE100 is the Simplified Technical English specification, owned by ASD and kept by its
Simplified Technical English Maintenance Group (STEMG). AECMA started the work in 1979 for
airlines whose mechanics did not all read English as a first language, and published the first
guide in 1986. It became ASD-STE100 in 2005. It is a free download from asd-ste100.org, and
defence, rail and other industries now use it too.

The picture [ste100-overview.png](ste100-overview.png) shows the same content on one sheet.
This file is a working summary, not the specification: for a document that must comply, the
user needs the specification itself.

## Structure

- **Part 1, writing rules**, in nine sections: words, noun clusters, verbs, sentences,
  procedures, descriptive writing, safety instructions, punctuation and word counts, writing
  practices.
- **Part 2, dictionary**: about 900 approved words. Each has one part of speech and one
  meaning. Words that are not approved are listed with the approved alternative.

## Limits

| Thing | Maximum |
|---|---|
| Procedural sentence (an instruction) | 20 words |
| Descriptive sentence | 25 words |
| Descriptive paragraph | 6 sentences, one topic |
| Noun cluster | 3 words |
| Instructions in one sentence | 1, unless the actions occur at the same time |

## Words

- Use a word with its approved meaning and part of speech only. "Close" is a verb ("Close the
  valve"); it is not an adjective that means "near".
- Use the same word for the same thing every time. Do not change "valve" to "tap" for variety.
- Technical names (nouns of the subject) and technical verbs (verbs of the subject) are
  permitted in addition to the dictionary. Use them in one form only.
- Do not leave out "the", "a" and "this" to shorten a sentence.

Common replacements:

| Not approved | Write |
|---|---|
| commence | start |
| ensure | make sure |
| prior to | before |
| replenish | fill |
| utilize | use |
| approximately | about |
| in order to | to |
| close (meaning near) | near |

## Verbs

| Form | Example | Status |
|---|---|---|
| Command (imperative) | Close the valve. | approved |
| Simple present | The valve closes. | approved |
| Simple past | The valve closed. | approved |
| Simple future | The valve will close. | approved |
| Infinitive | Turn the knob to close it. | approved |
| Past participle as adjective | The closed valve | approved |
| Progressive (-ing) | The valve is closing. | not approved |
| Perfect | The valve has closed. | not approved |
| Passive, in procedures | The valve must be closed. | not approved |

Use the "-ing" form only inside a technical name, for example "landing gear". Descriptive text
can use the passive voice only when it is necessary, for example when the agent is not known.

## Sentences

**Procedure.** Write a command. Put the condition first, the action second.

> Not STE: It is imperative that the operator ensures the hydraulic reservoir is replenished
> prior to commencing operation.
>
> STE: Make sure that the hydraulic reservoir is full before you start the operation.

**Safety instruction.** Start with a clear, simple command, then give the risk. WARNING is for
a risk of injury, CAUTION for a risk of damage.

> WARNING: Do not touch the brake unit until it is cool. Hot parts can cause injury.

**Description.** Use the simple present tense, one topic for each paragraph, and start the
paragraph with the topic sentence.

> The pump supplies fuel to the engine when the switch is on.

## Writing practices

- Use the active voice in procedures.
- Use a vertical list for complex text.
- Write one topic in each paragraph.
- Write numbers as digits, and keep the units.
- Count a number, a unit or a technical name as one word when you check the limits.

## Check before delivery

1. Is each instruction 20 words or less, and each descriptive sentence 25 or less?
2. Does each sentence give one instruction?
3. Is there an "-ing" verb, a perfect tense or a passive command? Rewrite it.
4. Does one thing have two names? Choose one.
5. Is there a long word where a short one says the same? Replace it.
